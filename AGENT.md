# Agent Instructions

## Commits and attribution

- Never add agent or AI self-attribution to commits, commit messages, PR titles, PR bodies, branch names, changelogs, or generated files.
- Do not include phrases such as `Generated by`, `Co-authored-by`, `AI`, `agent`, assistant names, model names, or tooling signatures unless the user explicitly requests them.
- Branch names must describe the work only and must not reference the agent or tool that created them.

## Commit message format

- Always use Conventional Commits correctly.
- Format commit messages as:

  ```text
  <type>(optional-scope): <description>
  ```

- Use an appropriate type such as `feat`, `fix`, `docs`, `test`, `refactor`, `chore`, `ci`, `build`, `perf`, `style`, or `revert`.
- Use `ci:` for CI workflow changes and `docs:` for documentation-only changes.
- Keep descriptions imperative, concise, and lowercase unless a proper noun is required.
